# risktrace

学业风险规则改权影响追溯库（Go，纯进程内存，由上层直接调用）。

## 功能

- 固定处理一个学期，学生以 ID 唯一标识。
- `AddStudent` 新增学生；`ReplaceFacts` 完整替换风险事实（不产生报告）。
- `Publish` 发布一组新权重（五个权重均 0-50），立即生效并产生不可变影响报告。
- `Report` 查询历史报告；`StudentInReport` 查询某名学生在该报告当时的事实、新旧得分与档位。

## 计分规则

GPA<2.0 加 GPA 权重；出勤下降>20% 加出勤权重；每门期中 D/F/W 加门数权重（该项封顶 45，门数不限）；无助学金、第一代大学生各加对应权重。总分封顶 100。0-30 低风险，31-60 中风险，61-100 高风险（边界包含）。判断阈值、两项封顶与分档边界固定。

## 实现要点

- 得分只依赖五个特征，引擎按特征签名聚合计数（736 个桶），发布时按桶计分再乘以人数，避免逐学生重算。
- 每名学生维护带全局序号的事实版本日志；报告记录发布时的序号，历史查询按序号二分定位当时事实，历史报告永不被后续修改改写。

## 验证

- `go test ./risk/`：小规模连续更新/改权与逐人重算对照，覆盖阈值相等、零权重、两层封顶、档位边界与报告不可变性。
- `go run ./cmd/scalecheck`：20 万学生 + 10 万次替换 + 1 万次发布 + 10 万次历史查询，报告耗时与峰值内存，并对最早/中间/最新报告做独立对照。
